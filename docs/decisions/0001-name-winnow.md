# 0001 — Name: winnow

Date: 2026-08-11
Question: What should the project and CLI be called?
Options: `winnow`; or a different new name.
Decision: Use `winnow`, with the tagline "reports only what your PR broke."
Reason: To winnow is to separate what matters from what does not; it describes reporting only new findings.
Cost: The npm package name is occupied, so published packages will use `@winnow/cli`.
Re-evaluate: Only if a real naming or trademark conflict prevents use.
