# 0006 — Public repository from the first commit

Date: 2026-08-11
Question: When should the repository become public?
Options: Make it public from the first commit; or wait for a later release.
Decision: Make it public from the first commit.
Reason: The licence must be decided before public contributions, and public visibility reinforces careful handling of credentials.
Cost: Early work is visible before the security model is complete.
Re-evaluate: Never; protect users with the README warning and no release, tag, or announcement before Part C.
