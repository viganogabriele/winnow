# 0005 — Apache-2.0 licence

Date: 2026-08-11
Question: Which licence should apply to winnow from its first public commit?
Options: Apache-2.0; or AGPL-3.0.
Decision: Use Apache-2.0 with DCO sign-off and no CLA.
Reason: It reduces adoption friction while keeping contribution governance simple, per spec §27.
Cost: It does not require SaaS wrappers to publish their modifications.
Re-evaluate: Only before accepting outside contributions that require a different governance model.
