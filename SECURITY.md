# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub Private Vulnerability Reporting feature. Do not open a public issue or disclose exploit details before a fix is available.

## Severity policy

For winnow, sandbox escape and credential leakage are the only P0 vulnerability classes (spec §27). Other reports are still welcome and will be assessed according to their impact.

## Current status

winnow is in early development and must not be run on untrusted repositories yet.
